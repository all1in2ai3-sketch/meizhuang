# Beauty Alarm 美妆闹钟

欧莱雅美妆科技黑客松本地演示，需求见 plan.md。

## 运行

Node.js 24，npm 11。首次运行 `npm ci`，然后 `npm run dev`。
打开 http://127.0.0.1:5173/ ，API 在 127.0.0.1:3001。

## 演示路径

1. 我的：设置偏好、大字体和自动播报。
2. 产品展柜：确认拥有 FIT ME 粉底液及 Colour Riche 唇膏，或手动录入自己的产品。
3. AI 灵感：输入需求、选择时间，生成预设演示方案并加入时钟。
4. 开始指导：可重复、暂停、替换缺少的产品、确认缩短方案。
5. 保存回顾：领取晨露，在花园查看进度。刷新后恢复本地记录。

## 真实 AI

复制 .env.example 为 .env，在本机设置 AI_BASE_URL、AI_MODEL、AI_API_KEY，重启服务。密钥仅在服务端使用。未配置时，页面明确使用预设演示方案。不要把密钥放入前端或 Git。

## 验证

- `npm run build`：类型检查与构建。
- `npm test`：业务规则。
- `npx playwright install chromium`，`npm run test:e2e`：流程、布局、图片与无障碍自动检查。

见 docs/QA.md 和 docs/ASSETS.md。当前版本是本地 Demo：真实模型、设备麦克风、屏幕阅读器和低视力用户验收仍需单独实测。浏览器页面关闭后不保证提醒。支持同时打开多个标签页；并发编辑冲突尚不自动合并。

## 新增亮点：成分花园

访问 /ingredients，或从首页、花园、FIT ME / CeraVe 产品详情进入。先拆解并收藏原料卡，再领取一次性新手晨露，培育两张卡后合成产品图鉴。完成原有美妆任务可继续获得晨露。首批为两款产品、四张原料卡，具体来源及规则见 plan.md 第二十五节。

## 2026-10-04 全功能扩展

新入口：
- /ingredients：20 张成分卡、6 款产品、搜索、分页与知识关联。
- /planner：晨晚例程、阶段目标、每天/工作日/每周提醒、日历导出。
- /context：实时天气、本地日程、音乐试听、香气偏好。
- /scan：包装 OCR、条码图片识别、候选确认和手动替代。

任务页增加计时、触觉、镜头自查、主观舒适度回顾；我的增加色彩语言和系统通知；花园增加材料、徽章、主题与小鹿装饰。

完整对照见 docs/FEATURE_MATRIX.md。文字模型及单帧实验观察共用 .env 模型配置，图片观察需要模型支持视觉输入。相机默认不上传；仅用户单独勾选同意后主动请求实验观察时发送 JPEG 单帧。

扫描首次需要联网下载 Tesseract worker 与 eng/chi_sim 模型，图片在浏览器中识别。低清包装识别准确性有限，必须人工确认。开发端 OCR 冒烟脚本：node scripts/ocr-smoke.mjs。
