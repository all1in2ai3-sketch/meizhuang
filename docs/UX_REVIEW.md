# 玩法整理与体验走查

## 设计决定（2026-10-04）
视觉主张：奶油白、鼠尾草绿与柔和的立体原料插画，沿用主站产品摄影。参考星露谷的发现、培育、收集循环，不使用像素表现。
内容计划：一个成分花园工作台，拆解、培育、图鉴三个视图。每个视图只有一个当前目标；资料按需展开。装饰和徽章放在独立成长页。
交互主张：拆解后直接进入对应产品的培育区；缺晨露时展示领取或任务入口；原料齐全后可以点亮图鉴。切换产品不丢失收藏。

## 助手模拟首次使用的发现
- 旧页同时出现像素地图、工具栏、完整成分手册、培育区和两个图鉴入口，操作重复。
- 首次进入默认看到未发现的地块，而发现原料的操作藏在工坊面板。
- 8 格分页把同一配方的原料拆开，难以判断还差什么。
- 大字开关占据全局页头，步骤朗读偏好又在任务准备页重复出现。

## 调整范围
- 合并重复玩法，默认展示当前产品的全部原料；保留查看全部 20 张原料的入口。
- 移除正在使用的像素画布及像素主题，保留已有收藏记录。
- 大字和自动朗读仅在设置页勾选，保留默认键盘操作、焦点与屏幕阅读器语义。
- 这是助手的流程走查，不是实际用户调研。

## 本轮验收
- 浏览器回归共 43 项：首轮 36 项通过；修正选择框 label 关联及成长页旧测试路径后，7 项重跑全部通过。
- 覆盖：真实任务奖励、拆解/培育/图鉴完整流程、零余额限制、重复领取防护、刷新保留、产品详情跳转、20 张原料可达、键盘操作、多标签打开。
- 三个玩法视图通过 axe WCAG A/AA 自动检查；320、375、768、1440 宽度均无横向溢出。另验证 320 宽大字模式。
- 25 项领域单元测试通过。构建通过。
- 人工检查桌面拆解页、手机培育页截图，保留原有柔和插画。自动无障碍检查不代替真实屏幕阅读器及用户试用。
- 辅助设置集中到 /profile，原料收藏和经济规则没有改动。用户原有浏览器存档未清除。
